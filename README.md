## The entry

Our own make.fun username: **rezimx01** — one word, nothing else. No explanation, no links, no pitch. Just the single username, 9 characters, inside the 30-character limit.

## How to run

```sh
python3 main.py
```

Stdout is exactly the single word `rezimx01`. When the grader sets `MAKEFUN_OUTPUT_DIR`, the same single word is also written to `$MAKEFUN_OUTPUT_DIR/username.txt`.
